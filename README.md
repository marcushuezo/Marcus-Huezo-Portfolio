View port

FullScreen - 960px and above - i followed lecture code and concepts. i Used 960px width and above as its the minimum screen width for the desktop layout. The navigation buttons fit across the screen in one row, and my introduction and profilo photo are beside each other.

tablet - 481px to 959px - i followed lecture code and concepts. i Used this range for medium sized screens. I adjusted the layout and sizing to fit screens larger than phones but smaller than full screen computers. navigation buttons are in two rows and places i travelled is in one row.

phone -  480px and below - i followed lecture code and concepts. i Used this range as it is the Indented size for phone screens. allows the content to fit within the screen. while styling i used single column formatting so the content stacks vertically.  

I Used Media queries in my html files to load the indented css based on what screen size i am veiwing from.

I used fuild design with percentage widths so that as my page adjusts to different screen sizes so as my content.



Color scheme 

The color scheme i went with is from the neutral palatte page on adobe color https://color.adobe.com/explore?q=Neutral+Palette

The palatte i went with remeinded me of light spring palatte, i picked it because it would be easy on the eyes and attratcive to look at with more mutted light tones.

The color scheme i used is called neutral-colors-contemporary-neutral-color-palette-owl-neutral-colors
Hex: #65695B, #9CA38E, #C0C4B7, #8A9EAB, #4C6170, #2B3E54, #EBE0DD, #D9C3B6, #EBE6DC

I used a cream background with bright blues and greens to make my main information stand out at the viewer.
On my form page, i changed the color of the form to a cool grey because i wanted contrast at the end of my website and did not want the green to over power the blue.

#2B3E54 I used dark blue for the text and headings so it would stand out against the cream background. for the headings i used white text on the gradient backgrounds for my navigation section, to make it easeir to read.




Gradients 

i used horizontal linear gradient in the header section where my navigation buttons are located. it starts off with a dark blue then blends into a lighter blue to mutted green. Gradient was positioned left to right. The navigation links have a darker blue background with a small, white border to stand out against the gradient.

in the footer, i used an angled linear gradient at 135 deg with the same colours. i chose a linear gradient because i wanted the header and footer to look a like but not the same. i used white text in the footer for the same reason i used it in the header.  

the reason i only used gradients in the header and footer because using them in the main section of my website would of probably distract the viewer from my main content. This is why i chose a cream background.
